# Public Repository Checklist

Before pushing this portfolio to a public repository:

- [ ] Read every file and confirm it reveals no private business information.
- [ ] Do not add private project repositories as submodules or copy their source into this repository.
- [ ] Do not upload `.env` files, keys, credentials, database dumps, backups, or customer data.
- [ ] Do not include real production URLs, internal hostnames, screenshots of private dashboards, or detailed architecture diagrams.
- [ ] Keep planned features clearly labeled as planned.
- [ ] Ensure all screenshots and demo data are synthetic.
- [ ] Run a secret scan and inspect the full Git history before publishing.
- [ ] Review repository visibility and account settings before the first push.

This starter is intentionally limited to high-level descriptions. It does not contain application source code or a working demo.
